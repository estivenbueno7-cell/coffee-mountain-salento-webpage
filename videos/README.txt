VIDEOS
======

Coloca aquí los videos de la web en MP4 (H.264) o WebM.

Luego abre media-studio.html para previsualizarlos y usa el fragmento generado para agregarlos a VIDEO_ITEMS en app.js.

Recomendación:
- 1080p máximo para videos principales.
- H.264 + AAC en MP4 para máxima compatibilidad.
- Comprime los videos antes de publicarlos.
- Evita archivos enormes; idealmente cada pieza web debería estar por debajo de 30–50 MB.
