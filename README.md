# Coffee Mountain Salento — V3

Rediseño completo orientado a conversión, marca y SEO local.

## Incluye
- Nueva landing premium responsive.
- Coffee Mountain Salento como marca principal.
- Hero, experiencias, Jeep Willys, historia, galería, reseñas, FAQ y CTA.
- WhatsApp directo en puntos estratégicos.
- Páginas indexables para tres experiencias.
- SEO técnico, canonical, Open Graph, Schema.org, sitemap y robots.
- Se conservan las fotografías existentes del proyecto.

## Después de publicar
1. Conecta el dominio definitivo.
2. Verifica Google Search Console.
3. Envía `sitemap.xml`.
4. Conecta/optimiza Perfil de Empresa de Google.
5. Sustituye los textos de reseñas de ejemplo por reseñas reales.
